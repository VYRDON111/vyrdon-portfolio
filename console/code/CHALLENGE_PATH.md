# Challenge Path

## Who Can Challenge

Any party involved in a claim can challenge:
- The evidence used in the decision
- The decision itself
- The enforcement action taken

## Challenge Process

1. Challenge filed with reference to decision ID
2. Enforcement paused (if action not yet executed)
3. Evidence window opened for additional submissions
4. Re-evaluation conducted
5. New decision issued (may confirm or change the original)
6. Enforcement resumes based on new decision

## Challenge Does Not Guarantee Change

A challenge triggers re-evaluation. It does not guarantee a different outcome. If the evidence has not changed, the decision will not change.
