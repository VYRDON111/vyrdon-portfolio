# Settlement Path

## Multi-Party Settlement

Settlement distributes funds to multiple parties based on a PASS decision.

## Settlement Process

1. PASS decision verified for the settlement claim
2. Settlement amounts validated against the claim
3. Pre-conditions checked
4. Funds distributed to all parties atomically
5. All distributions recorded with evidence
6. Settlement certificate issued

## Partial Settlement

If a settlement involves multiple sub-claims and some produce PASS while others produce HOLD or NO_PASS, only the PASS sub-claims are settled. The remainder stays in escrow.
