# Customer Overview

## What RootPass Means For You

When you send a payment, wire a transfer, or trade on an exchange, you expect the transaction to be verified correctly. But how do you know the verification was actually done right?

RootPass tests whether the verification itself can pass. It checks:
- Does the proof chain exist?
- Is it complete?
- Does it contradict itself?
- Can the decision be proved?

If the proof chain is complete and consistent: **PASS** — your transaction proceeds.
If the proof chain is broken: **NO_PASS** — the problem is documented.
If evidence is missing: **HOLD** — the system waits instead of guessing.
