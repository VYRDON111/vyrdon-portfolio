# VYRDON Overview

VYRDON builds proof-enforced transaction infrastructure.

## The System

1. **Methodology** — how decisions are made (four-pillar law, contradiction detection, PASS/NO_PASS/HOLD)
2. **Proof** — that decisions are correct (TLA+ formal verification, ZK proofs, model checking)
3. **Mechanism** — how decisions are enforced (escrow, timelock, circuit breaker, multi-sig)
4. **Cases** — that the system works on real data (market-specific case studies, patterns, failures)
5. **Technology** — how the system is built (architecture, services, APIs, evidence pipeline)
6. **Registry** — what types exist (decision codes, claim types, schemas, catalogs)
7. **Open Review** — that anyone can challenge (public audit, submissions, responses)

## The Law

TRUE ROOT = PASS. FALSE ROOT = NO_PASS. MISSING ROOT = HOLD. No root, no pass.
